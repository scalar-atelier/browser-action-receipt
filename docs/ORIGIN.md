# Project origin and clean boundary

`browser-action-receipt` is maintained by SCALAR Atelier Co., Ltd.

SCALAR Atelier's private product contains an approval-before-browser-action flow and target revalidation behavior. This repository reimplements that company-owned behavior as a small, independent public contract. It does not copy the product UI, private Git history, characters or artwork, customer material, gateway authentication, Tauri commands, persistence model, or internal ArtifactRef implementation.

The synthetic fixture pages and tests in this repository were written for this project. They contain no third-party product UI, credentials, production URLs, or user data. OpenMausBot and other automation projects may be evaluated as potential integration hosts, but no third-party source is incorporated unless its license and attribution are recorded in the commit that adds it.

Before public release, the repository must pass a full-history secret scan and a source-boundary review from a clean clone.
